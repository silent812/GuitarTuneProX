# GUITAR TUNE PRO X — RED METAL EDITION

Guitar tuner VST3 plugin for Windows.

Created by SILENTBROKEN.

## Features

- Real-time guitar tuning
- YIN-based pitch detection
- Strobe tuner
- Six-string guitar fretboard visualizer
- AUTO, MANUAL and CHROMATIC modes
- 12 guitar tunings
- Reference pitch adjustment from 432 Hz to 445 Hz
- Fine tuning display in cents
- Dark wood interface with red and orange accents

## Installation

1. Close your DAW.
2. Download the VST3 package from GitHub Releases.
3. Extract the folder named Guitar Tune Pro X.vst3.
4. Copy it to:

   C:\Program Files\Common Files\VST3\

5. Open your DAW and rescan VST3 plugins.
6. Load Guitar Tune Pro X.

## Building from source

Requirements:

- Windows 10 or Windows 11
- Visual Studio 2022 with C++ development tools
- CMake 3.22 or newer
- Internet connection to download JUCE 8.0.6

Build commands:

    cmake -S . -B build
    cmake --build build --config Release
